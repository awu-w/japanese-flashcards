# 日语学习卡片（手机版）

这是 `flashcards_JP.py` 的手机网页版本，默认读取同目录的 `notesSample_jp.txt`。

## 最简单的使用方法

将本文件夹免费发布到 GitHub Pages、Cloudflare Pages 或 Netlify，即可获得免费网址，不需要购买域名。发布后用手机浏览器打开；在 iPhone Safari 中选择“分享 → 添加到主屏幕”，在 Android Chrome 中选择“安装应用”。

直接双击 `index.html` 也可以打开界面，但浏览器通常不允许网页自动读取旁边的 TXT；此时点“更换 TXT”并选择笔记文件即可。通过免费网页托管打开时，TXT 会自动载入。

## 更新学习内容

编辑或替换 `notesSample_jp.txt` 后重新发布。格式保持为：日语句子、假名、罗马音、中文；“单词”和“详细拆解”为可选内容。
